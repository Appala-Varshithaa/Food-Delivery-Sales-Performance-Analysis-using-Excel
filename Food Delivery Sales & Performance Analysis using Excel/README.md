# 🍔 Food Delivery Sales & Performance Analysis Using Excel

## 📌 Project Overview

This project focuses on analyzing food delivery data to evaluate sales performance, customer behavior, restaurant revenue, payment methods, and delivery operations.

An interactive dashboard was developed using Excel and WPS Office with PivotTables, PivotCharts, KPI cards, and slicers to transform raw data into meaningful business insights and support data-driven decision-making.

## 🎯 Project Objectives

- Analyze overall order and revenue performance.
- Identify top-performing restaurants by revenue.
- Understand revenue distribution across payment methods.
- Analyze delivered, cancelled, and failed orders.
- Evaluate delivery performance.
- Calculate key business performance indicators (KPIs).
- Build an interactive dashboard using slicers.
- Generate actionable business insights and recommendations.

## 📂 Dataset Structure

The workbook contains the following sheets:

### 1. Raw_Orders
Contains the main food delivery order records.

**Used for:**
- Order analysis
- Revenue analysis
- Payment method analysis
- Order status analysis
- Delivery performance analysis

### 2. Customers
Contains customer-related information.

**Used for:**
- Customer activity analysis
- Customer purchasing behavior
- Customer-level performance analysis

### 3. Restaurants
Contains restaurant-related information.

**Used for:**
- Restaurant-wise order analysis
- Revenue comparison
- Identification of top-performing restaurants

### 4. Food_Menu
Contains food item and menu information.

**Used for:**
- Food item performance analysis
- Popular food item identification
- Food category analysis

### 5. Delivery_Partners
Contains delivery partner information.

**Used for:**
- Delivery partner performance analysis
- Partner-level comparisons
- Delivery-related metrics

### 6. Project_Plan
Contains the planned tasks and structure of the analytics project.

### 7. Data_Dictionary
Provides descriptions of the dataset fields and their meanings.

## 🎛️ Interactive Dashboard Features

The dashboard includes slicers for:

- **Payment Method:** Filter data by UPI, Card, Wallet, Cash, or Unknown.
- **Order Status:** Filter data by Delivered, Cancelled, or Failed.

These slicers provide interactive filtering for the PivotTables and charts connected to them.

## 🚀 How to Use

1. Clone or download this GitHub repository.
2. Open `Food_Delivery_Analytics.xlsx` in Microsoft Excel or compatible spreadsheet software.
3. Review the `Data_Dictionary` sheet to understand the available fields.
4. Explore the PivotTables and PivotCharts.
5. Open the `Dashboard` sheet.
6. Use the available slicers to filter the connected charts.
7. Review the KPI cards and visualizations.
8. Interpret the results and identify business improvement opportunities.
